# YBX XTApp

Клиент YBX для Xteink X4 Classic и X4 Pro с совместимой прошивкой Gancao, XTApp API 2.26. Историческая версия 1.6.17 для более старого API сохранена отдельно.

Gancao (甘草) и Licorice — названия одной семьи официальной прошивки. CN и EN/Global — её региональные варианты. Внутренний канал `gancao` отделяет актуальный пакет от исторического и не обозначает китайский регион. Совместимость определяется поддерживаемым XTApp API и форматом пакета; установка на закрытых CN-устройствах отдельно не проверена.

## Возможности

- Привязка устройства по коду (RFC 8628) с текстом и QR.
- Полки «Все / Читаю / Хочу прочитать / Прочитано / Загруженные» и каталоги
  Яндекс Книг, WB Книг и ЛитРес; объединённый поиск.
- Потоковая загрузка EPUB с HTTPS-редиректами и без передачи Bearer-токена на
  чужие origin; лимиты 32 МиБ на книгу и 32 записи о загрузках.
- Чтение и удаление локальных книг, отчёты `book.downloaded` с сохранением
  одного ID при повторах.
- Статистика чтения, календарь, достижения; карточка экрана сна 480×800.
- Ручная настройка KOSync и отдельного ключа для цитат.

## Основной сервер и зеркала

- Основной адрес — `https://my.ybx.app`.
- Европейское зеркало — `https://emy.ybx.app` (и `esync`/`eopds`), португальское —
  `https://pmy.ybx.app` (и `psync`/`popds`) — для тех, у кого основной адрес
  заблокирован. Зеркала сохраняют путь и общий магазин данных.
- Сервер выбирается в Help & diagnostics → Server: Auto / Main / Europe /
  Portugal. В Auto запрос, до которого не удалось достучаться, уходит на следующий
  хост (main → Europe → Portugal), каждый хост — не больше раза на запрос; ответы
  HTTP хост не меняют, а ответившее зеркало остаётся предпочтительным ещё
  5 минут. Main, Europe и Portugal говорят ровно со своим адресом.
- Для цитат приложение принимает **все три** доверенные базы (`my.ybx.app`,
  `emy.ybx.app`, `pmy.ybx.app` + `/api/v1/crosspoint/kosync`): сервер отдаёт базу
  того хоста, через который пришёл запрос, поэтому обход работает и для цитат.
  Любой другой хост, схема или путь отклоняются.

## Установка

Установите приложение из магазина XTApp либо скопируйте официальный пакет
`package/YBX-1.7.0.xtapp` на карту и откройте его на совместимом устройстве.

## Экспорт и обновления

Пакет экспортируется официальным Studio. Старый community-packer использует
другую схему упаковки/шифрования и не воспроизводит этот экспорт.

```bash
python3 tools/validate_source.py
python3 scripts/publish_xtapp.py --dry-run --no-release --notes "Что изменилось"
python3 scripts/publish_xtapp.py --no-release --site /path/to/site-checkout --notes "Что изменилось"
```

По умолчанию используется `source/ybx-studio` и пакет с совпадающей версией.
Другие версии в `package/` не мешают проверке. До записи в каталог сайта
проверяются исходники, manifest, структура контейнера и SHA-256 по
`releases/1.7.0.json`. Это локальная запись проверенной пары исходники/экспорт,
а не криптографическое доказательство расшифровки кода. При изменении runtime
нужны новый экспорт Studio и проверенная запись нового выпуска; нельзя просто
переписывать SHA старого пакета для обхода проверки.

`--dry-run` не создаёт и не изменяет пакет или каталог сайта. `--no-release`
не создаёт GitHub-релиз. Без этого флага создаётся GitHub-релиз-архив.
Скрипт не деплоит сайт. Историческая команда `build_ybx_stock_source.py`
сохранена только для старой 1.6.17.

## Учёт чтения

XTApp передаёт позицию через KOSync, а сервер оценивает минуты. Клиент не
создаёт таймер. Снимки `read_sec` передаются отдельно для сравнения, без начисления минут. См.
[схему учёта](READING-TIME.md) и [передачу выпуска Installer](RELEASE-HANDOFF.md).

## Тесты и проверка

Тесты исполняют Lua-приложение в wasmoon (Lua 5.4) на моках хоста — нативный Lua
не нужен.

```bash
npm install --prefix tests
npm test --prefix tests          # tests/run-tests.js
node tests/run-studio-tests.js
python3 -m unittest discover -s tests -p test_release_pipeline.py
python tools/validate_source.py  # официальный экспорт Studio и запись выпуска
```

`validate_source.py` проверяет исходники и заголовок пакета: манифест,
дрейф встроенного модуля, версию и точную длину зашифрованной code-секции.
Сами байты code-секции зашифрованы ключом устройства, поэтому без образа
прошивки не читаются; длина при этом точна и ловит пакет, собранный из старых
исходников.

## Безопасность

- В репозитории нет токенов и личной конфигурации.
- Токен доступа хранится в app-private каталоге на SD и не печатается в логах
  сборки или выполнения.
- Bearer-токен не уходит на чужие origin при редиректах загрузки.
- Ключ цитат — только HTTPS и только доверенные хосты YBX.

## Ограничения

- Здесь проверены исходники, моки и формат пакета; аппаратные пути (Wi-Fi,
  фрагментация кучи, SD, реальный экран) требуют проверки на устройстве.
- Code-секция `.xtapp` зашифрована для ключа устройства и не расшифровывается
  без образа прошивки.

## Структура проекта

- `source/ybx-studio/` — runtime 1.7.0, manifest, модули app и фирменные assets.
- `source/ybx/` — исторический клиент 1.6.17 для более старого API.
- `releases/1.7.0.json` — сверка исходников и официального экспорта.
- `package/YBX-1.7.0.xtapp` — официальный пакет Studio.
- `scripts/publish_xtapp.py` — проверка и подготовка отдельного каталога Gancao.
- `tests/` — Lua runtime, OTA, очередь диагностики и публикационный pipeline.
