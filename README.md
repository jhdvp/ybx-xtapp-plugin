# YBX XTApp

Отдельный клиент YBX для **стоковой прошивки Xteink X4 Pro (Licorice, host API 2.18)**
и сборки CrossPoint 2.0 XTApp. Это самостоятельный пакет `.xtapp` на Lua, а не
порт веб-панели: у приложения собственный интерфейс, а каталог, поиск, загрузки,
статистика, экран сна и настройка KOSync работают через публичный API YBX.

> **Это не YBX Native.** Кастомная YBX Reader развивается отдельно и не
> устанавливается на стоковую прошивку. Здесь — только стоковое издание.

## Возможности

- Привязка устройства по коду (RFC 8628) с текстом и QR.
- Полки «Все / Читаю / Хочу прочитать / Прочитано / Загруженные» и каталоги
  Яндекс Книг, WB Книг и ЛитРес; объединённый поиск.
- Потоковая загрузка EPUB с HTTPS-редиректами и без передачи Bearer-токена на
  чужие origin; лимиты 32 МиБ на книгу и 32 записи о загрузках.
- Чтение и удаление локальных книг, отчёты `book.downloaded` с сохранением
  одного ID при повторах.
- Статистика чтения, календарь, достижения; карточка экрана сна 480×800.
- Ручная настройка KOSync и отдельного ключа для цитат.

## Основной сервер и зеркало

- Основной адрес — `https://my.ybx.app`.
- Европейское зеркало — `https://emy.ybx.app` (и `esync`/`eopds`) — для тех, у
  кого основной адрес заблокирован. Зеркало сохраняет путь и общий магазин
  данных.
- Для цитат приложение принимает **обе** доверенные базы
  (`https://my.ybx.app/api/v1/crosspoint/kosync` и
  `https://emy.ybx.app/api/v1/crosspoint/kosync`): сервер отдаёт базу того хоста,
  через который пришёл запрос, поэтому обход работает и для цитат. Любой другой
  хост, схема или путь отклоняются.

## Установка

1. Скопируйте `package/YBX-1.6.16.xtapp` в корень SD-карты.
2. Установите через **All Files** на устройстве.
3. Откройте приложение из ящика **Ink App**.

## Сборка

Пакет собирается из `source/ybx` в два шага: подготовка каталога сборки и
упаковка внешним пиннутым пакером (MIT, см. `source/ybx/README.txt`).

```bash
python scripts/build_ybx_stock_source.py /path/to/staged-ybx
python touch-licorice-apps/xtpack.py /path/to/staged-ybx -o package/YBX-1.6.16.xtapp
```

`build_ybx_stock_source.py` копирует runtime, проверяет, что встроенный в
`index.lua` модуль экрана сна совпадает с `src/sleep_card.lua`, собирает
`lockscreen.lua` для стоковой блокировки и добавляет блок `lockscreen` в
манифест.

## Тесты и проверка

Тесты исполняют Lua-приложение в wasmoon (Lua 5.4) на моках хоста — нативный Lua
не нужен.

```bash
npm install --prefix tests
npm test --prefix tests          # tests/run-tests.js
python tools/validate_source.py  # манифест, дрейф sleep-card, версия и .xtapp
```

`validate_source.py` проверяет исходники и заголовок пакета: манифест,
дрейф встроенного модуля, версию и точную длину зашифрованной code-секции.
Сами байты code-секции зашифрованы ключом устройства, поэтому без образа
прошивки не читаются; длина при этом точна и ловит пакет, собранный из старых
исходников.

## Безопасность

- В репозитории нет токенов и личной конфигурации.
- Токен доступа хранится в app-private каталоге на SD и не печатается в логах
  сборки или выполнения.
- Bearer-токен не уходит на чужие origin при редиректах загрузки.
- Ключ цитат — только HTTPS и только доверенные хосты YBX.

## Ограничения

- Здесь проверены исходники, моки и формат пакета; аппаратные пути (Wi-Fi,
  фрагментация кучи, SD, реальный экран) требуют проверки на устройстве.
- Code-секция `.xtapp` зашифрована для ключа устройства и не расшифровывается
  без образа прошивки.

## Структура проекта

```
ybx-xtapp-plugin/
├── source/ybx/                     # runtime: единственный источник пакета
│   ├── manifest.json               # app_id=ybx, version, entry, api=2.18, permissions=[net]
│   ├── index.lua                   # приложение: UI, сеть, загрузки, статистика, KOSync, цитаты
│   ├── icon.png                    # иконка 180×180, 1 bpp (секция иконок пакета)
│   ├── src/
│   │   ├── sleep_card.lua          # общий модуль карточки экрана сна
│   │   └── lockscreen.lua          # точка входа стоковой блокировки
│   └── README.txt                  # дизайн, совместимость и полный changelog
├── scripts/
│   └── build_ybx_stock_source.py   # staging: копирует runtime, сверяет sleep-card, собирает lockscreen.lua
├── tools/
│   └── validate_source.py          # проверка манифеста, дрейфа sleep-card и соответствия .xtapp
├── tests/
│   ├── YbxAppTest.lua              # Lua-тесты на моках хоста
│   ├── run-tests.js                # запуск тестов на wasmoon (Lua 5.4)
│   └── package.json                # зависимость wasmoon и `npm test`
├── package/
│   └── YBX-1.6.16.xtapp            # собранный пакет для SD-карты
├── .github/workflows/
│   └── validate.yml                # CI: validate_source.py + npm test
├── .gitignore
└── README.md
```

Как связаны части:

- `source/ybx/` — единственный runtime. В `index.lua` модуль `src/sleep_card.lua`
  встроен между маркерами `-- BEGIN/END SHARED SLEEP CARD`.
  `build_ybx_stock_source.py` проверяет, что встроенный блок не разошёлся с
  `src/sleep_card.lua`, и собирает `lockscreen.lua` = локальная обёртка модуля
  плюс `src/lockscreen.lua`.
- `tools/validate_source.py` сверяет исходники с заголовком `package/*.xtapp`
  (версия и манифест, точная длина зашифрованной code-секции), поэтому пакет,
  собранный из старых исходников, виден сразу.
- `tests/` исполняют `index.lua` в wasmoon на моках `ctx`; путь к `index.lua`
  подставляет `run-tests.js`, нативный Lua не нужен.

В сам `.xtapp` попадают только `manifest.json`, `index.lua`, сгенерированный
`lockscreen.lua` и `icon.png`. `README.txt`, `src/`, `tests/`, `tools/` и
`scripts/` остаются в репозитории и в пакет не входят.

Версия приложения следует версии плагина CrossPoint, который оно повторяет:
**1.6.16**.
